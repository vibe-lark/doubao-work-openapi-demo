# 飞书 SSO 与三个 Tab

2026-10-15，独立 Node 版。后续工作区调整见 [对话列表与业务按钮](WORKSPACE.md)。本次修正的是浏览器登录和演示入口：旧版全局用户令牌不再等同于所有访问者已经登录。

## 登录链路

浏览器从「使用飞书 SSO 登录」跳转飞书账号授权页。服务端校验一次性 state 与浏览器 Cookie 一致后兑换用户令牌，再调用飞书 `authen/v1/user_info` 验证身份。验证成功后签发随机、不透明的 HttpOnly / SameSite=Lax 会话 Cookie；HTTPS 下附加 Secure。姓名与头像来自飞书实际响应。

每个浏览器登录对应独立的服务端令牌文件，权限 0600，目录被 Git 忽略。HTTP 请求不读取旧版全局令牌。业务 API 要求有效的已验证身份；匿名或过期会话返回 401。写请求校验自定义请求头与同源 Origin。退出只撤销当前浏览器的本应用登录、清理当前用户本标签页对话，不撤销飞书账号登录，也不影响其他浏览器。

会话最长七天，用户令牌仍受上游有效期约束；只有取得 refresh_token 才能续期。飞书首次授权或再次授权仍可能需要确认。当前验证的是飞书账号 SSO，不是企业自定义 IdP / SAML 接入。

## 三个入口

| Tab | 演示内容 |
| --- | --- |
| Playground | 云端对话列表、历史读取、连续追问、新建对话及停止回复；不自动附加商机记录 |
| 系统集成 | 模拟商机工作台；业务按钮自动组装上下文并创建独立真实任务，侧栏展示结果 |
| 接口列表说明 | 11 项接口的用途、支持范围、限制和历史证据；未验证项保留标记 |

Playground 和系统集成分别持有云端会话，浏览器记录按用户及 Tab 隔离。切换 Tab 不停止正在处理的任务。旧链接 `#embed`、`#capabilities` 分别兼容系统集成和接口列表。

## 本次验证

- 真实飞书授权、身份查询与回调成功；登录后显示真实用户信息，刷新后仍保持登录。
- Playground 两轮真实回复完成，第二轮正确复用第一轮的演示代号。
- 系统集成使用另一会话，根据附加商机记录指出预算尚未正式确认。
- 页面脚本无法读取 HttpOnly 登录 Cookie；无 Cookie 的独立请求返回 401。
- 真实退出后业务请求返回 401，刷新仍停留登录页，本地对话已清理；再次登录回到退出前的系统集成 Tab。
- 三个 Tab 在 390 / 768 / 1512 像素宽度下无页面横向溢出，检查了登录页、Playground 和系统集成截图。
- `cd web && npm run build && npm test` 通过严格 TypeScript、生产构建及全部 8 项回归测试。

自动化 SSO 测试使用测试专用的身份提供方替身，覆盖两个用户的令牌隔离、重启恢复、state Cookie 缺失与回放拒绝、跨站写请求拒绝、退出撤销且不影响另一用户。这是本应用会话隔离的验证，不代表已用两个真实飞书账号证明上游全部跨用户边界。生产入口从不加载该替身。

## 部署边界

当前为本地 Node BFF 调用真实飞书身份服务及豆包工作正式环境；模拟的仅是商机业务数据。公开部署仍需 HTTPS、正确回调地址、飞书应用可见范围和组织准入配置。没有在本次改造中新增云端部署或企业 IdP。文件上传和自动写回不属于本次三个 Tab 的操作演示。
