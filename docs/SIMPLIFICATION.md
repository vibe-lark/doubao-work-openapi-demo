# 能力边界与侧栏嵌入演示改造

> 本文记录首版精简。当前入口已升级为飞书 SSO + Playground / 系统集成 / 接口列表说明三个 Tab；鉴权与最新验收以 [SSO-TABS.md](SSO-TABS.md) 为准。

## 目标与范围

只保留两个主入口：解释豆包工作 API 的能力边界；模拟业务系统通过侧栏访问豆包工作。当前改造针对独立 Node 版，不改写 `platform-hosted` 的平台实现。

此前首页先要求 OAuth，随后展示完整工作台。现在未授权也能浏览能力及示例；真实调用才需要授权。移除主前端中的会话管理页、文件页、调试台、批量边界执行器、通用组件库与重复主题。相应后端 API、历史报告与测试套件保留，旧页面可由 Git 历史找回。

## 视觉与交互约定

- 视觉来源：相邻本地豆包工作项目的官方 Logo、浅蓝 `#CAE4FF`、黑白、系统字体、留白和圆角。
- 主结构：顶部两个导航；能力页四类入口与逐项展开；嵌入页单一商机、一条跟进记录、一个豆包侧栏。
- 控件：原生语义 React button / select / textarea / details，提供键盘焦点、禁用状态、可访问标签。无需额外图标或插画；流程信息本身构成视觉说明。
- 窄屏：业务与侧栏上下排列；按钮打开侧栏后滚动定位。回复表格仅在自身区域横向滚动。
- 示例数据和预置回答均显式标注；切换模式后分别展示各自的对话。
- 正式架构保持 React → 同源 Node BFF → 豆包工作 API。云端调用没有被本地模拟 Agent 替代。

## 简化规模

前端运行依赖由 48 个降到 2 个（React 与 React DOM），主 JS 由约 875 KB 降至约 243 KB，最终构建结果以 Vite 输出为准。删除未使用的工作台组件与抽象层；直接使用原生 fetch 与已有 BFF。源码保留严格类型检查、依赖锁定及必要的回归测试。

## 仍然存在的边界

- 本次正式环境验证只覆盖侧栏的创建会话、发文字、读回复、多轮与停止。没有补测所有文件、SSE、分页、名称、归档、隔离和速率限制。
- 2026-10-13 PPE 历史报告保持原样；其中 O6 的 PASS 仅是环境配置观察，不代表双环境业务验证。
- 侧栏采用每 4 秒轮询最新 100 条消息，不宣称展示了 SSE 增量传输。
- 业务系统和跟进记录是模拟数据；不自动获取其他业务数据，也不自动写回字段。
- sessionStorage 只恢复同一浏览器标签页；新标签页或清除存储后不能恢复旧句柄。
- 服务继承原仓库的本机单用户架构。公开多用户部署仍需补充访问控制与令牌隔离。
- 本次仅推送审阅分支，不改变远程默认分支或部署公网生产服务。
