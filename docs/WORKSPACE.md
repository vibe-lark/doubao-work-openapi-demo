# 对话列表与业务按钮

2026-10-15，独立 Node 版。SSO 与同源 BFF 保持原实现，所有任务仍调用真实豆包工作 API。

## Playground

左侧读取 `GET /v1/sessions`，只展示名称为 `Playground · …` 或旧版 `Playground 对话` 的本演示会话，不将账号下其他业务对话混入列表。每页读取 50 条，通过「加载更早对话」继续翻页。新对话以首条问题命名。

选择云端对话时分页读取消息，按 `reply_id` 对齐问题与回答，再复用原 session 继续追问。新建不会清空旧对话；每个已载入会话保持独立发送和轮询状态，切换对话、切换 Tab、收起侧栏不会中断云端任务。

本标签页状态继续按账号及 Tab 保存到 sessionStorage，兼容旧版单对话记录。刷新可恢复本页进度；退出清理本地状态，重新登录后可从云端列表取回 Playground 会话。系统集成任务列表目前仅保存在本标签页，不提供跨设备任务列表。

## 系统集成

模拟 CRM 数据明确标注，三个按钮放在其对应的业务区域，每次点击创建独立任务，自动发送，无需再点聊天发送按钮：

| 入口 | 自动附加的数据 | 任务 |
| --- | --- | --- |
| 最近跟进 → 检查记录 | 商机基础信息、最近跟进 | 检查 BANT 缺失证据 |
| 下次拜访 → 准备拜访 | 商机基础信息、最近跟进、拜访时间/联系人/目的/参会人 | 生成议程及优先问题 |
| 商机 → 分析风险 | 商机基础信息、最近跟进、预计签约时间及未确认标记 | 区分事实与推测并给出风险和行动 |

侧栏可展开实际发送的上下文、切换任务、继续追问与停止生成。这里只分析模拟业务记录，不写回商机字段。

## 页面精简

去掉演示大标题、英文标语、重复 Logo、示例模式、提示词按钮、手动附上下文选项和页尾说明。接口页去掉重复标题，验证范围折叠；必要的未验证状态、错误提示、SSO 和模拟数据标记保留。手机端对话列表按需展开。
